# 🚌 Lao Transit Open Data (vte-bus-gtfs)
### Part of the **Quick Route (QR)** initiative by [QRLao.org](https://qrlao.org)

Vientiane City Bus General Transit Feed Specification (GTFS) data. Part of a research initiative to enhance public transport accessibility in Lao PDR.

📊 **Current Status:** `v1.0.0 Released` (Passed Validation: 0 Errors / 0 Warnings)  
🏢 **Publisher:** Lao Transit Open Data (Research Lab)  
📍 **Coverage:** Vientiane Capital (Route 13: Talat Sao - Nongkhamsean)

---

## 🚀 Overview
This repository provides the first open-source GTFS feed for the public bus system in Vientiane. Our goal is to provide high-quality, standardized transit data to support commuters, researchers, and developers in creating better transport solutions.

## 📂 Dataset Details
- **Route 13:** Fully mapped with precise GPS coordinates.
- **Fares:** Updated to the current rate of **25,000 LAK** (April 2026).
- **Format:** GTFS Static (Standard CSV files zipped).
- **Validation:** 100% compliant with the Canonical GTFS Schedule Validator.

## 🛠 Files in this Repository
- `agency.txt`: Vientiane Capital State Bus Enterprise (VCSBE) contact info.
- `stops.txt`: Geographically verified bus stop locations.
- `fare_attributes.txt`: Official fare structure.
- `vte-bus-gtfs.zip`: The complete bundle for transit app integration.
- `map.geojson`: Visual representation of stops for GIS analysis.
